Polymarket sells daily temperature markets — "Will London's high be 32°C?" Each bracket pays $1 if YES. The scanner finds brackets where the price is lower than what the weather models say it should be.
How markets resolve

Signal types
⚡ Guaranteed ARB Cost < 100¢
3+ adjacent brackets cost less than $1 combined. One MUST resolve YES. Risk-free profit regardless of temperature. Act fast — these close quickly.
🎯 Core-3 +EV Cost 100–110¢
Buy forecast bracket ±1. Covers a 1-bracket forecast error. Profitable if the forecast is roughly right.
🌡 Single bracket Exact match
Only the exact forecast bracket. Higher EV per dollar, zero error tolerance. Best for high-confidence Today signals only.

① Day badge — forecast horizon
Today = most reliable. +1 = still good. +2 = moderate uncertainty. +3 = use wider bracket only.
② Error margin — model uncertainty
±1.5°C ensemble = the 50 ECMWF model runs span ±1.5°C around the forecast. The Core-3 bracket covers this. When it shows ±4°F (no ensemble) it's a fixed estimate — less precise.
③ Confidence pill — should you trade?
🟢

🟡
Medium

🔴
Low

⑤ Forecast — bias corrected
The big number is the bias-corrected forecast — what we actually target. "Raw 34°C → adj. -1°C bias" means ECMWF said 34°C but over the last 14 days it's run 1°C warm for this city, so we target 33°C. Below it, the local model chip (Met Office / JMA / DWD etc.) shows what the national weather service says. Δ < 1°C = models agree = higher confidence.
⑦ Accuracy bar — 14-day model track record
Avg error: typical miss size (🟢 <1°C, 🟡 1–2°C, 🔴 >2°C). Bias: systematic warm/cold tendency — if large, the correction is already applied to the forecast. Within 1°C: % of days the model was within 1°C of actual (🟢 ≥70%, 🟡 50–70%, 🔴 <50%).
